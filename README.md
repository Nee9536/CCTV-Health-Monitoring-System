Master Sheet Import

Please ensure the Excel file follows the exact 5-column format:
Sr. No. | Digital NVR | Device Name / Camera & NVR | IP Address | Location

Do not change column names or order.
Enter one device per row.
Ensure IP addresses and device details are correct.
Upload the file in .xlsx format.
No additional columns are allowed.

CCTV Scan – User Instructions

Start CCTV Scan: Initiates the device connectivity check.
Working / Live: Shows devices responding to the network scan.
Offline: Shows devices that are not responding.
Live Scan Preview: Displays real-time device status during scanning.
Response (ms): Shows the device response time.
Remarks: Displays the scan result, such as Ping Reply Received or Request Timed Out.
Open Latest Report: Opens the most recently generated scan report.
Open Reports Folder: Opens the folder containing all generated reports.
Refresh Dashboard: Refreshes the displayed device information.
Note: Ensure the Master Sheet is updated and the devices are reachable through the network before starting the scan.
